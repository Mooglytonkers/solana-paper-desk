# Paper Desk Rules
PAPER ONLY. No keys, no signing. Live mode (not implemented) requires Daniel to sign every transaction himself.
Roles: SCAN (gather, never judge) -> VERIFY (hard gates, default SKIP) -> EXECUTE (paper fills sized from state.json) -> EXIT (config rules).
All numbers live in config.py; code never modifies them. Every task incl. skips -> logs/tasks.csv; fills -> logs/trades.csv.
